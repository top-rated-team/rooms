10 of them. Copy one, paste it into a fresh agent, and that is the whole job. Nothing on this page needs reading twice.

  1. Open a terminal in the project.
    cd ~/Documents/ChatGPT\ Ads
  2. Check the tree is clean before anyone writes in it.
    node scripts/check-parcels.mjs && npm run verify
  3. Start the agents in a wave — press Copy this prompt, paste into a new agent, one agent per prompt.
  4. Wait for every agent in that wave to report. Do not run anything while they type.
  5. Run the same two commands again. If they pass, commit. Then the next wave.
